# Unified Media Manager

Универсальный инструмент для сбора, дедупликации и синхронизации медиафайлов и документов между локальными дисками и облачными хранилищами (Mail.ru, Яндекс.Диск, Google Drive).

## Возможности

1. **Локальный сбор (`collect_local`)**: Рекурсивный поиск медиа и документов на ПК с копированием в целевую папку. Дубликаты пропускаются на основе SHA-256 хеша.
2. **Облачная дедупликация (`dedup_cloud`)**: Поиск и удаление дубликатов внутри облака. Использует двухэтапный алгоритм (сравнение по размеру → вычисление хеша) для максимальной скорости.
3. **Сверка ПК и Облака (`compare_pc_cloud`)**: Сравнение содержимого локальной папки и папки в облаке по именам и размерам файлов.
4. **Безопасность**: Вместо мгновенного удаления файлы перемещаются в папку «На проверку». Генерируется визуальный HTML-отчет с превью изображений для ручной верификации перед окончательным удалением.
5. **Мультиоблачность**: Поддержка Mail.ru, Яндекс.Диска и Google Drive. Провайдер выбирается динамически через аргумент командной строки `--provider`, без необходимости изменения конфигурационных файлов.

## Установка и настройка

1. Клонируйте репозиторий или создайте папку проекта.
2. Создайте виртуальное окружение и активируйте его:
~~~bash
   python -m venv venv
   source venv/bin/activate  # Для Windows: venv\Scripts\activate
~~~
3. Установите зависимости:
~~~bash
   pip install -r requirements.txt
~~~
4. Скопируйте .env.example в .env и заполните его своими данными:
5. Отредактируйте config.yaml под ваши нужды (списки расширений и игнорируемых папок).
## Использование
Все операции запускаются через main.py. Облачный провайдер выбирается флагом --provider (по умолчанию mailru).
## Режим работы (DRY_RUN)
По умолчанию скрипт работает в безопасном тестовом режиме (DRY_RUN=True в .env). В этом режиме:
- Ничего не удаляется и не перемещается
- Только формируется отчет о том, что было бы сделано
- Вы можете спокойно проверить результаты
Когда вы убедились, что все работает корректно, измените в .env:
~~~env
DRY_RUN=False
~~~
1. Сбор файлов с локального диска
~~~bash
   python main.py collect_local --category media
   python main.py collect_local --category documents
~~~
2. Очистка дубликатов в облаке.
Запустите (в тестовом режиме по умолчанию):
~~~bash
   python main.py dedup_cloud --provider mailru --category media --dry-run
~~~
Изучите отчет. Если все корректно, измените DRY_RUN=False в .env и запустите снова:
~~~bash
   python main.py dedup_cloud --provider yandex --category media
~~~
Файлы будут перемещены в папку На_проверку, а не удалены безвозвратно.
3. Сверка локальной папки и облака
~~~bash
   python main.py compare_pc_cloud --provider google --category media
~~~
4. Визуальная проверка дубликатов (локально)
Для запуска расширенной проверки с генерацией HTML-отчета:
~~~bash
   python main.py audit_local --folder D:/Media_Collection --category media
~~~

После этого откройте файл duplicates_report.html в браузере, проверьте файлы глазами и подтвердите перемещение дубликатов в безопасную папку.
## Безопасность и рекомендации
1. Всегда делайте бэкап перед массовыми операциями удаления.
2. Скрипт использует двухэтапную проверку: сначала группирует файлы по размеру, затем считает SHA-256 только для совпадающих по размеру. Это ускоряет работу в десятки раз.
3. Файлы не удаляются сразу. Они перемещаются в изолированную папку На_проверку с сохранением структуры. Окончательное удаление этой папки вы выполняете вручную после проверки.
